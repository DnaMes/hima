# Himalaya Web

## Goal

Standalone local browser GUI for the installed Himalaya v2.1.0 CLI. Keep the
mail client local, loopback-only, and backed by the existing Himalaya config and
desktop keyring.

## Rules

- Read `HANDOFF.md`, `README.md`, and the latest design spec before editing.
- Never copy passwords, OAuth tokens, 1Password tokens, or keyring contents into
  source, tests, browser storage, logs, or Git.
- Keep user-facing UI text German; keep code, tests, and planning documents
  English.
- Use synthetic mail data for automated tests. Do not send, delete, bulk-move,
  or tag real mail during tests.
- Preserve loopback binding and the API session boundary.
- Use Conventional Commits when commits are explicitly requested.

## Commands

```bash
npm install
npm run typecheck
npm test
npm run build
npm audit --omit=dev --audit-level=high
```

The live service is `systemctl --user status himalaya-web.service`. Its active
unit and the active Omarchy widget are user configuration outside this repo;
keep reproducible templates under `deploy/`.
